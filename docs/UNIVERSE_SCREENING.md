## Flag key

| flag | question it raises |
|---|---|
| `LEND` | interest-bearing by design (riba) |
| `YIELD` | return is yield on deposits |
| `DERIV` | gharar / maysir |
| `GAMBLE` | maysir |
| `MEME` | no underlying activity; pure speculation |
| `CEX` | issuer revenue includes margin, futures and lending |
| `STABLE` | reserves earn interest; also carries no price signal to rank on |
| `DEX` | a spot AMM may be judged differently from a perp venue |
| `RWA` | depends entirely on the underlying |
| `GAME` | some titles are gambling-adjacent |
| `PRIV` | delisting/regulatory risk rather than a fiqh objection |
| `DEFI` | too broad to judge alone; check the protocol's actual business |

## Why breadth matters here

Information ratio scales as `IC * sqrt(breadth)`, so the number of names a cross-sectional strategy ranks over moves results more than signal refinement does. Going from the shipped 15-name whitelist to 104 names is roughly a 2.6x improvement for identical skill.

One caveat the count hides: the unflagged names are almost entirely L1/L2 infrastructure, the most mutually correlated group in crypto. Cross-sectional selection feeds on dispersion *between* names, so effective breadth is lower than the headline number. The categories that would add real dispersion -- gaming, DeFi, memecoins -- are the flagged ones.
